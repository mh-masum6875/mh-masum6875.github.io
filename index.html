Case studies

WSN-YOLO (LightYolo-SSO)

MSc dissertation · ultra-lightweight object detection for wireless sensor networks

Problem. Accurate detection models are often too heavy for wireless vision sensor nodes, while lightweight models can fail when sensing conditions shift.

Method. Instead of pruning an existing model, I searched the architecture space directly with Sperm Swarm Optimization (SSO) over a 15-dimensional space, using a multi-objective fitness that balances accuracy, FLOPs, parameters and inference time (weights 0.4 / 0.3 / 0.2 / 0.1). Built on YOLOv7, trained on the Intel Berkeley Research Laboratory (IBRL) dataset: 31,067 grayscale images, two classes (normal, anomaly).

Adaptive LightYolo-SSO

Energy-efficient anomaly detection via dynamic early-exit inference

Idea. One trained network, two modes. With early exit on, confident samples leave the network early; with it off, the full network runs as a baseline. Both modes share the same weights, with only 25,062 extra parameters (1.8% overhead) for the exit branches.

Architecture. The LightYolo-SSO backbone gets two exit branches (global average pooling, a fully connected layer with ReLU and dropout, then a linear layer for the two class logits) at layers 14 and 21, with thresholds of 0.90 and 0.85.

Where samples exit (3,109-sample IBRL test set)

Exit 1 · 98.6%
98.6% leave at Exit 1 · 0.7% at Exit 2 · 0.7% run the full network

Accuracy stays flat at 99.55% across aggressive, default and conservative thresholds while the exit distribution and cost shift, confirming all three exit points work. Training converged over 150 epochs without overfitting (best checkpoint at epoch 72: 99.77% train / 99.74% validation). Energy and latency figures are FLOP-proportional estimates; hardware-measured validation is planned.
