Research projects

PyTorchYOLOv7Neural architecture search

WSN-YOLO (LightYolo-SSO)

An ultra-lightweight YOLO for Wireless Sensor Networks, with its architecture found by Sperm Swarm Optimization over a 15-dimensional search space. 78% fewer parameters and a 93.8% smaller model than YOLOv7-tiny (2.9 MB vs 47 MB) while keeping 99.57% mAP@0.5.

View on GitHub →
Early exitAnomaly detectionEdge AI

Adaptive LightYolo-SSO

Dynamic early-exit inference for energy-efficient anomaly detection. 99.55% accuracy at 92.2 M MACs vs 261.2 M for the full network; 98.6% of samples exit at the first branch.

View on GitHub →

Common thread: treating efficiency as a design constraint rather than a post-training statistic, with controlled comparisons that report accuracy together with compute cost and deployment conditions.
